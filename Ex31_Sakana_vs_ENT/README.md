# Ex31: ENT проти Sakana-CMA на CIFAR-10

Відповідає **§4.4** дисертації («Порівняльний аналіз методу ENT із сучасними
методами злиття»): пряме порівняння ENT з індустріальним методом **Sakana-CMA**
(Akiba et al., *Evolutionary Optimization of Model Merging Recipes*, arXiv:2403.13187,
Nature Machine Intelligence 2024) та п'ятьма іншими методами злиття на CIFAR-10.

## Мета

MNIST (`Ex30_HetMerge_ENT/`, табл. 4.3) — еталонний, добре контрольований бенчмарк.
Ex31 перевіряє метод ENT на складнішому наборі (CIFAR-10, кольорові зображення,
нетривіальна внутрішньокласова варіативність) і в сценарії, найсприятливішому для
головного конкурента: **спільна попередньо навчена база** — саме той режим, для
якого розроблявся Sakana-CMA (§4.4.1, «Обґрунтування вибірки наборів даних»).

## Протокол

1. Базова мережа (SmallCNN, ~95К параметрів) навчається 10 епох на всіх 10 класах.
2. `Parent A` донавчається 25 епох лише на класах 0–4, починаючи з ваг бази.
3. `Parent B` донавчається 25 епох лише на класах 5–9, починаючи з ваг бази.
4. 7 методів злиття застосовуються без доступу до тренувальних даних (лише
   holdout-вибірка 25 прикладів/клас для EA-пошуку ENT та калібрації ENT-FT).

**Методи (7):** Weight Average, Task Arithmetic, TIES-Merging, DARE-TIES,
Sakana-CMA, ENT (наш), ENT-FT (наш). Обґрунтування вибору методів — §4.4.1
дисертації (представники трьох парадигм злиття: інтерполяційні, селективні,
еволюційні).

Один запуск, seed=42 (те саме обмеження, що й для MNIST — див. §4.5 дисертації,
«Відсутність статистичних тестів»).

## Фігура (`figs/`)

`make_figs_cifar.py` читає `results/sakana_vs_ent.tsv` (7 методів, нічого не

  (б) мінімальна точність по класу — захист найслабшого класу;

  (г) окупність обчислень — час злиття (с) на один збережений клас.

## Ключовий результат

ENT перевершує Sakana-CMA на цьому наборі: `+1,3%` точності (0,626 проти 0,613) та
`+8,8%` балансу (0,490 проти 0,402), при цьому Sakana-CMA фактично не перевершує
тривіальне усереднення ваг (0,613 ≈ 0,615) — пошарова CMA-ES-оптимізація
коефіцієнтів інтерполяції не долає бар'єр інтерференції ваг при комплементарному
злитті. TIES-Merging та DARE-TIES деградують катастрофічно (8/10 та 5/10 класів
відповідно). Повний аналіз — §4.4.1–4.4.2 дисертації.

## Обмеження

Див. §4.5 дисертації. Коротко для цього експерименту: один запуск (seed=42, без
статистичних повторів); лише одна архітектура (SmallCNN) і один набір даних
(CIFAR-10); ENT-FT на цьому наборі *поступається* базовому ENT (0,547 проти 0,626)
— на відміну від MNIST, де калібрація дає приріст (§4.4.1, «Поведінка ENT-FT на
CIFAR-10») — лінійна калібрувальна голова недостатня для семантично складніших ознак.
