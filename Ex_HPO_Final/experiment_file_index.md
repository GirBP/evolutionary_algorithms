# Структура файлів глобального бенчмарку (Ex_HPO_Final)

Офіційний ідентифікатор глобального експерименту — **`Ex_HPO_Final`**.

Нижче наведено повний перелік ключових файлів та директорій, що стосуються масштабного порівняння 11 методів на 43 задачах:

## 1. Головні скрипти
- `analyze_full.py` — головний аналітичний скрипт генерації глобального звіту, результатів тестів Фрідмана/Неменьї та баєсівського аналізу.
- `benchmark/l4_objective.py` (та інші файли у `benchmark/`) — кодова база з усіма визначеними задачами та функціями об'єктивів.
- `methods/sacma_v3.py` (та ін.) — алгоритми оптимізації, що підлягають тестуванню.

## 2. Сирі результати (Raw Data)
Усі 4730 евалуацій фізично збережені у папці `results/`. Дані розділені за топологічними класами:
- Об'єкти в `results/L0/`, `results/L2/`, `results/L2_MLP_PD1/`, `results/L3_NAS_SUPER/`, `results/L4/`, `results/L5_FCNET/`.
- Зведений файл сирих даних: `results/GLOBAL_ANALYSIS/aggregated_results.csv`.

## 3. Аналітичні звіти (у `results/GLOBAL_ANALYSIS/`)
- `Summary.md` — глобальний звіт з усіма детальними таблицями по рангах, тестах та показниках.
- `09_Method_Victories_Report.md` — звіт частотності перемог (No Free Lunch Analysis).
- `10_Efficiency_Report.md` — звіт порівняння витрат процесорного/реального часу (RCU).
- `bayesian_signed_rank.csv` — математичні результати баєсівського порівняння методів.

## 4. Статистична візуалізація (у `results/GLOBAL_ANALYSIS/`)
*Ці файли призначені для вставки у текст дисертації (через `![]()`).*
- `01_CD_Diagram_Global.png` — діаграма критичної різниці (Critical Difference) Неменьї.
- `03_Rank_Heatmap.png` — теплова карта рангів для аналізу загальної успішності.
- `04_Pareto_Front.png` — Парето-компроміс (Час RCU — Збіжність).
- `06_Win_Rate_Matrix.png` — квадратна матриця перемог методів один над одним.
- `07_Family_Boxplot.png` — розмах квартилів та статистика стабільності (IQR).
