### 2. Агрегація результатів для теплової карти (Rank Heatmap)

[ФАКТ З ДЖЕРЕЛА] Для дослідження локальної ефективності та переносимості методів оптимізації між різними доменами було побудовано теплову карту рангів (`03_Rank_Heatmap.png`). Вихідними даними для генерації матриці слугували попередньо обчислені значення рангів (засновані на `median_loss`) кожного методу для ізольованих експериментів.

[ФАКТ З ДЖЕРЕЛА] Процес побудови включав дворівневу агрегацію:
1. Залежно від типу ландшафту (surrogate proxies, NAS-benchmarks, реальне навчання тощо), задачі було згруповано у шість класів (Tiers). 
2. Для кожного алгоритму всередині кожного класу було розраховано локальний середній ранг. 
Для структурної послідовності відображення векторів (методів) по вертикальній осі матриці було застосовано експліцитне сортування за глобальним середнім рангом зі спаданням успішності згори донизу. 

[ВИСНОВОК] Застосування інвертованої градієнтної шкали (де мінімальне математичне значення 1.0 жорстко інтерпретується як ідеальний результат) дозволило об'єктивно розмежувати профілі алгоритмів. Подібне агрегування дає змогу виявляти доменні спеціалізації методів (наприклад, стійкість до зашумлених просторів високої розмірності), відокремлюючи їх від алгоритмів, що мають високу загальну, проте нестабільну локальну ефективність.
