# Ex00 — Валідація метрики RCU

Перевірка стійкості та коректності RCU (Relative Compute Units) у порівнянні з Wall Clock, Process Time, Thread Time.

## Запуск

```bash
python Ex00/ex00.py
```

## Тести

1. **Стабільність під шумом**: CV метрик при чистих умовах vs 4 фонових потоки
2. **L1 vs RAM дискримінація**: RCU розрізнює кеш-bound та RAM-bound навантаження
3. **Лінійність масштабування**: R² при збільшенні навантаження 1x..5x
