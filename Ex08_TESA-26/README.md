# Ex08: TESA-26, E-HTA — еволюційне неструктуроване проріджування нейронних мереж

Відповідає підрозділу **§2.3** дисертації («Еволюційні методи неструктурованого
проріджування нейронних мереж»).

## Мета

Неструктуроване проріджування (unstructured pruning) видаляє окремі ваги нейронної
мережі за бінарною маскою m ∈ {0,1}^N (§2.3.1). Стандартні функції оцінки
важливості (Magnitude, WANDA, SparseGPT, RIA) використовують **глобальний** поріг
відсікання, однаковий для всіх шарів, що субоптимально при надзвичайних рівнях
розрідженості (s ≥ 0,90), коли глобальне відсікання руйнує критичні шляхи
передавання сигналу. Ex08 перевіряє дві авторські альтернативи:

- **TESA-26** (Taylor-Evolutionary Sparsity Allocation, §2.3.3) — CMA-ES оптимізує
  вектор пошарових квот k = (k₁, …, k_L) (частку ваг, що зберігаються у
  кожному шарі) за Тейлорівською оцінкою значущості Ω_l з ітеративним
  перерахунком (ISR) та штрафом за деактивовані нейрони (NFP);
- **E-HTA** (Evolutionary Hessian-Trace Approximation, §2.3.2) — CMA-ES оптимізує
  пошаровий коефіцієнт балансу λ_l між градієнтною та магнітудною
  компонентами оцінки Ω = |g · w| + λ_l w², при незмінному
  **глобальному** пороговому проріджуванні.

**Масштабне порівняльне дослідження (§2.3.4, `Ex08` як зведення серії Ex04–Ex07)**
зіставляє 10 методів (4 існуючих: Magnitude, WANDA, SparseGPT, RIA + 6 авторських) на
6 наборах даних (`blobs`, `circles`, `moons`, `spirals` — SimpleMLP;
`cnn`, `resnet` — FashionMNIST/CompactCNN, CompactResNet) і 12 рівнях розрідженості
(50–97%), 3 повтори (seed = 42, 123, 999) — 1116 записів. Метрика якості — F1-macro;
статистика — тест Фрідмана з post-hoc Немені (α = 0,05).

## Як запустити

**Повний бенчмарк** (навчає моделі й переоцінює всі 32 методи з нуля — важкий прогін,
потребує PyTorch, завантажує FashionMNIST через `torchvision` при першому запуску
CNN/ResNet-методів):

```bash
cd code
python3 ex08_run.py --list                 # перелік зареєстрованих методів
python3 ex08_run.py --method tesa26         # один метод, усі датасети/рівні
python3 ex08_run.py --method all -q         # усі методи, швидкий (quick) режим
```

Результати кожного методу пишуться у `data/results_<method>.json` (не входить до
публічної копії — генерується локально; агрегація в CSV/MD-таблиці `results/`
виконується окремо скриптом `save_results.py` — він лежить у корені папки
`Ex08_TESA-26/`, не в `code/`).

> `figs/new_fig_2_10_ex08_cd_5methods.png` і `figs/new_fig_2_11_ex08_f1_vs_sparsity_v2.png` — оригінальні рисунки 2.10 та 2.11 дисертації (байт-у-байт; перший відтворюється запуском `code/regen_figures.py`).

**Відтворення фігур дисертації** (лише читає наявні `results/*_table.csv`, нічого не
перенавчає — швидко, без PyTorch-навчання):

```bash
cd code
python3 regen_figures.py      # Рисунки 2.10 (CD-діаграма) і 2.11 (F1 vs sparsity), 5-методний зріз
python3 make_extra_figs.py    # Додаткові ілюстративні рисунки (не з дисертації)
```

`regen_figures.py` перевірено: виводить і зберігає (`figs/friedman_stats.txt`) ранг
TESA-26 = **2.04**, χ² = **18.050**, CD = **1.245**, N = **24** — точний
збіг із дисертацією (див. карту нижче).
