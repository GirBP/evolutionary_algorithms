# Формалізація задачі надзвичайного неструктурованого прунінгу ШНМ

## 1. Нейронна мережа як параметризована функція

Нехай f_θ : X → Y — нейронна мережа з параметрами θ ∈ ℝᴺ, де N = Σₗ nₗ — загальна кількість ваг, L — кількість шарів, nₗ = |θₗ| — кількість параметрів шару l.

Мережа — композиція шарів:

    f_θ(x) = hₗ ∘ hₗ₋₁ ∘ … ∘ h₁(x),   hₗ(z) = σₗ(Wₗ·z + bₗ)

де Wₗ ∈ ℝ^(dₗ × dₗ₋₁) — матриця ваг, bₗ — зсув, σₗ — нелінійність.

## 2. Прунінг як маскування

Неструктурований прунінг вводить бінарну маску m ∈ {0, 1}ᴺ, що визначає підмножину активних параметрів:

    θ̃ = m ⊙ θ

де ⊙ — поелементне множення (маска Адамара).

Спарсність:

    s = 1 − ‖m‖₀ / N = 1 − (Σᵢ mᵢ) / N

## 3. Оптимізаційна задача

Нехай D = {(xᵢ, yᵢ)}ⁿ — набір даних, L — функція втрат. Задача прунінгу:

    m* = arg min_{m ∈ {0,1}ᴺ}  L(f_{m⊙θ}; D)
    при обмеженні:   ‖m‖₀ ≤ ⌈(1−s)·N⌉

Це NP-hard задача комбінаторної оптимізації: C(N, ⌊(1−s)N⌋) можливих масок.

## 4. Режим "надзвичайної" спарсності

Стандартний прунінг: s ∈ [0.5, 0.8].
Надзвичайний (extreme): s ∈ [0.90, 0.99].

При s → 1 виникають специфічні проблеми:

### 4.1. Зв'язність графа обчислень

Мережу можна представити як двочастковий граф Gₗ = (Vₗⁱⁿ, Vₗᵒᵘᵗ, Eₗ) для кожного шару, де ребра Eₗ відповідають ненульовим вагам. Прунінг видаляє ребра. Маска допустима, якщо:

    ∀l ∈ {1,…,L}:  deg⁺(v) > 0  ∀v ∈ Vₗᵒᵘᵗ  ∧  deg⁻(v) > 0  ∀v ∈ Vₗⁱⁿ

Інакше існує "мертвий" нейрон, що обнуляє інформаційний потік.

### 4.2. Колапс рангу

При високій спарсності ефективний ранг Wₗ різко падає:

    rank_eff(W̃ₗ) = (Σᵢ σᵢ)² / (Σᵢ σᵢ²)  ≪  min(dₗ, dₗ₋₁)

де σᵢ — сингулярні числа замаскованої матриці. Це означає втрату репрезентативної потужності шару.

## 5. Розподіл спарсності по шарах

Глобальна спарсність s розподіляється між шарами як вектор s = (s₁, …, sₗ):

    Σₗ (1 − sₗ)·nₗ = (1−s)·N

Задача layer allocation — знайти оптимальний s:

    s* = arg min_s  L(f_{m(s)⊙θ}; D)
    при   Σₗ(1−sₗ)nₗ = (1−s)N,   sₗ ∈ [0, 1)

## 6. Scoring-функції (релаксація комбінаторної задачі)

Оскільки точне розв'язання NP-hard, використовують score-based релаксацію:

    Ωᵢ = S(θᵢ, ∂L/∂θᵢ, Hᵢᵢ, …)   ∀i ∈ {1,…,N}

і зберігають top-k ваг за Ω:

    mᵢ = 𝟙[Ωᵢ ≥ Ω₍ₖ₎]

де Ω₍ₖ₎ — k-та порядкова статистика.

Приклади S:
- Magnitude:     Ωᵢ = |wᵢ|
- Taylor FO:     Ωᵢ = |wᵢ · gᵢ|          (gᵢ = ∂L/∂wᵢ)
- Hessian-trace: Ωᵢ = |wᵢ · gᵢ| + ½·wᵢ²·Hᵢᵢ
- WANDA:         Ωᵢ = |wᵢ| · ‖Xₗ‖₂      (Xₗ — вхідна активація шару)

## 7. Residual architectures: структурні обмеження

Для мереж із skip connections вигляду x_{k+1} = σ(F(xₖ) + S(xₖ)) виникає структурна зв'язаність: шари в межах одного residual block функціонально залежні.

Якобіан блоку b:

    Jᵦ = σ'(·) · (∏_{l∈Mᵦ} W̃ₗ  +  ∏_{l∈Sᵦ} W̃ₗ)

де Mᵦ — шари main path, Sᵦ — skip path.

Необхідна умова не-колапсу: ‖Jᵦ‖_F > 0, тобто хоча б один з доданків ненульовий. Це додає групове обмеження: маски шарів всередині блоку не можуть бути довільними незалежно.

## 8. Формалізація з урахуванням обчислювальних ресурсів

У практичній постановці додається resource constraint. Нехай C(m) — вартість пошуку маски m (у FLOP або wall-time):

    m* = arg min_m  L(f_{m⊙θ}; D)
    при   ‖m‖₀ ≤ k,   C(m) ≤ B

де B — бюджет обчислень. Це мотивує використання proxy-scores (magnitude, Taylor) замість прямої оптимізації з оцінкою на даних.
